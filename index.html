📷 Bilde

Legg teststripen på en lys grå eller hvit bakgrunn. Hele stripen kan ligge hvor som helst i bildet og kan være vannrett eller loddrett.

✨ Automatisk gjenkjenning

Appen søker etter de tre fargefeltene. Hvis den bommer, kan du velge manuell markering og trykke én gang på hvert av de tre feltene.

🧪 Kalibrering

Fargeskalaen er tilpasset teststripe-boksen din: klor 0 / 0,5 / 1 / 3 / 5 mg/l, pH 6,8 / 7,2 / 7,6 / 8,0 / 8,4 og TA 0 / 80 / 120 / 180 / 240 mg/l.
